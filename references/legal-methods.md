# 法学研究方法速查

## 选择方法的顺序

先判断问题性质，再选择方法：

| 问题类型 | 优先方法 | 核心产出 |
|---|---|---|
| 法条含义不明 | 法教义学 | 解释结论与适用边界 |
| 同案不同判 | 案例研究 | 裁判规则、事实类型、分歧原因 |
| 制度设计争议 | 法政策分析 | 利益衡量与制度后果 |
| 域外制度可否借鉴 | 比较法 | 可移植条件与本土化限制 |
| 大量裁判样本 | 实证法学 | 检索式、样本、变量、发现 |
| 新技术冲击旧概念 | 概念重构 + 类型化 | 新概念、识别标准、规则后果 |
| 通行类比存在争议 | 类比方法反思 | 相似—差异双轨分析、弱保护或限定适用 |
| 多部门法交叉 | 法律效果与体系衔接 | 民刑、民税、民诉、民商等规范分工 |

## 法教义学分析

基本路径：

1. 确定问题最终落在请求、抗辩、责任、权利归属、证明责任还是法律效果上。
2. 找到现行法上的主规则，不急于创设新规则。
3. 拆解构成要件与法律效果，说明争议发生在哪一环。
4. 解释争议要件：文义、体系、目的、历史、当然、反对、限缩或扩张解释。
5. 检查是否需要法条联动，例如用规范目的较强的条文指引法律效果条文。
6. 回应反对观点。
7. 给出适用规则、例外、证明要求和边界。

避免：

- 只摘录法条，不说明条文如何适用于争点。
- 只给价值判断，不说明现行法依据。
- 把例外规则写成一般规则。

## 案例研究

适合处理裁判分歧、事实类型、司法适用边界。

最低要求：

- 写明检索平台、关键词、时间范围、筛选标准。
- 区分指导性案例、参考案例、公报案例、普通裁判文书。
- 对每个案例提取：事实、争点、法院说理、裁判结论、可归纳规则。
- 说明样本局限，不能把少数样本伪装成全国裁判趋势。

## 比较法

四步：

1. 说明比较对象与中国法问题的对应关系。
2. 介绍域外规则及其制度背景。
3. 分析域外模式自身的兴衰、例外和批评。
4. 分析差异：法体系、司法结构、市场环境、监管逻辑。
5. 回到中国法的法条结构，说明中国方案为何可以不同。
6. 提炼可借鉴部分，而不是直接移植结论。

常见句式：

- “域外法并不能直接回答中国法上的解释问题，但可提示……”
- “考虑到我国现行规范已将……作为制度前提，本文仅借鉴其……”

## 法政策分析

可用于补强解释结论，但不能替代规范依据。

关注：

- 激励结构。
- 风险分配。
- 交易成本。
- 第三人保护。
- 可执行性和司法成本。

写法要求：

- 先说明现行法上的入口，再展开政策后果。
- 政策结论要能转化为强弱不同的规则，例如弱保护、例外豁免、比例原则回调、程序性证据开示。
- 不把“公平”“效率”“创新”作为自足结论。

## 概念重构

适合处理新技术、新交易、新人格利益、新财产形态。

步骤：

1. 指出现有概念标签为什么不准确。
2. 说明新事实中真正变化的利益结构或法律效果。
3. 提出新概念，但必须给出功能定义。
4. 将新概念转化为识别标准、权利义务或法律效果。
5. 说明新概念不覆盖哪些情形。

范式：

- “并非 A，而是 B。”
- “B 的规范意义在于……”
- “因此，在……情形中，应适用……；在……情形中，则不宜……”

## 类型化与差序规制

适合处理不宜一刀切的问题。

步骤：

1. 找出决定法律效果强弱的变量，如违法严重性、伦理可责性、公共利益损害、当事人保护必要性、技术可控性。
2. 建立类型或光谱。
3. 为每一类型配置不同法律效果。
4. 说明类型之间的转换条件。

常见法律效果梯度：

- 支持请求。
- 部分支持。
- 驳回请求。
- 转由公法责任、行政监管或刑事追缴处理。
- 承认权利但弱化救济。

## 类比方法

类比不能只找相似点。采用“相似—差异”双轨分析：

1. 明确被类比对象的规则功能。
2. 说明新问题与旧规则在哪些事实结构上相似。
3. 说明差异是否会破坏旧规则的正当性。
4. 必要时修正要件，而非整体搬用。
5. 如果只能部分成立，应给出弱保护、低强度保护或限定适用结论。

## 多部门法衔接

民法、刑法、行政法、税法、诉讼法交叉时，先分清问题层次：

- 行为是否违法。
- 私法上是否发生返还、赔偿、归属或抗辩。
- 公法上是否追缴、没收、处罚或监管。
- 程序上谁负证明责任、是否需要证据开示或报告衔接。

不要把一个部门法的价值判断直接替代另一个部门法的法律效果判断。

## 实证法学

必须交代：

- 数据来源。
- 检索式。
- 时间范围。
- 排除标准。
- 编码规则。
- 复核方式。
- 样本局限。

没有这些说明，不应作强统计结论。
