# 本地法学论文原文风格规则

本文件依据法学核心期刊论文库中的原文编写。样本以王迁、孔祥俊、崔国斌、李琛、蒋舸等知识产权法学者论文为主，另有其他核心期刊文章。原文由 PDF 转换而来，可能存在分页、字间空格和 OCR 字符；这些格式噪声不属于写作风格。不得把二次整理笔记中的“通俗摘要”“应试启发”“一句话概括”当作作者原文。

## 样本中反复出现的写法

- 王迁：《如何研究新技术对法律制度提出的问题？——以研究人工智能对知识产权制度的影响为例》先区分新技术带来新问题、没有带来新问题和凸显旧问题三种情形，再分别说明研究方法；《技术措施保护与合理使用的冲突及法律对策》把直接规避与提供规避手段分开，并按危害程度配置不同法律后果。
- 王迁：《论平面美术作品著作权的保护范围——从“形象”与“图形”的区分视角》把争议压缩为一个可操作的分类测试，再说明分类如何限制复制权的范围。
- 孔祥俊：《商业数据保护的实践反思与立法展望——基于数据信息财产属性的保护路径构想》先比较学理研究与保护实践，再说明知识产权保护与反不正当竞争保护的功能差异，最后提出专条方案及其边界。
- 李琛：《知识产权“客体—对象”区分论解析》把名相问题与实质问题分开，先对旧说作同情理解，再提取其规范意义，避免在术语争论中直接跳到结论。
- 蒋舸：《论知识产权许可费损失的计算》把实际损失、侵权获利、许可费损失和法定赔偿分别放入损害填补与遏制功能中，逐项说明证据的作用，避免用一个抽象的“利益平衡”概括全部理由。

这些是论证动作的例子，不是可照抄的句子。生成文本时只能迁移“先区分什么、依据如何推出、法律效果如何配置”的关系，不能复制原文措辞。

## 标题和目录的共同特征

本地论文库中的标题并不追求句法整齐。王迁的标题常以“对象＋体系”“对象＋冲突及对策”呈现问题，曹博的标题以“对象＋属性辨析”直接提出定性任务，孔祥俊的标题常把“法律构造”与“规制逻辑”并列，蒋舸的标题则通过“关系”“反思”“计算”等词提示论证动作。这些标题的共同点是：对象明确，争点集中，法律效果可预期，章节之间具有先后关系。

标题拟定应服从论文论证，而不是服从单一句式。一级标题可以是名词性结构，也可以是带有“检视、辨析、定性、配置、规制”等动作的结构；二级标题则应进一步说明本节处理的是客体、构成要件、适用条件、法律效果还是救济边界。主谓宾句式只在需要明确法律动作时使用，不得作为统一模板。

目录至少应呈现四个层次：第一章提出事实或规范问题，第二章清理对象的构成和既有法边界，第三章检验替代性保护路径，第四章完成法律定性，第五章配置具体行为规则和救济限度。不同论文可以合并或拆分章节，但不能让“问题提出”之后直接跳到“对策建议”，也不能在定性尚未完成前直接讨论责任范围。

标题中出现“路径”“机制”“逻辑”“困境”等词时，必须在标题或相邻标题中说明其具体所指。例如“邻接权保护的客体障碍”比“邻接权保护路径的困境”更清楚，“一般条款的审查方法与救济界限”比“一般条款的适用机制”更能提示正文内容。标题不宜使用“赋能、破题、闭环、范式升级、系统性治理”等宣传性或空泛表达。

## 一、原文中可迁移的表达机制

### 1. 一句一判断

原文通常先给出一个可以判断真假的命题，再在下一句补充依据、条件或例外。不要把现象、评价、结论和政策口号压在同一句中。

推荐顺序：

> 现象或规则是什么。该规则的适用前提是什么。前提在本文事实中是否成立。因此，法律效果应如何配置。

例如，不写“数字技术深刻改变了产业格局，带来了复杂而严峻的根本性困境，亟须构建立体化治理体系”，而写“该技术改变了作品的利用方式，但现行法已经规定了其中的部分行为。需要判断的是，新增行为是否超出既有权利的控制范围；若未超出，无须另设权利，若已超出，再讨论解释或立法上的补充。”

### 2. 连接词承担推理，不承担气氛

优先使用能够说明关系的连接：

- 因果：`因此`、`因而`、`由此`、`这意味着`
- 转折：`但是`、`然而`、`不过`、`尽管如此`
- 条件：`如果`、`只有在……时`、`除非`、`在……情形下`
- 解释：`即`、`也就是说`（只在确有必要澄清同一含义时使用一次）
- 收束：`据此`、`由此可见`、`可见`（段尾使用，不要句句使用）

连接词之后必须有内容上的关系。删除仅用于制造“学术感”的“值得注意的是”“在此基础上”“进一步而言”“不难发现”。

### 3. 先承认，再限定，再提出自己的判断

王迁、孔祥俊、李琛等文章常先说明既有路径为什么有吸引力，再指出其成立条件或遗漏，最后调整法律效果。这里的“但是”必须指出具体缺口，不能只作语气转折：

> 该路径能够解释……，其依据在于……。但是，它把……作为当然前提，而该前提在……情形下并不成立。因而，问题应改为……。

不要把“旧观点完全错误—本文方案完全正确”写成二元对立；除非材料确实支持，使用“不能解释”“适用范围有限”“容易导致”“尚不足以推出”等限度表达。

### 4. 段落必须有层次递进

每个论证段至少回答四个问题：

1. 本段要证明什么；
2. 依据是什么（法条、案例、学说、事实或比较法材料）；
3. 依据为什么能推出该结论；
4. 该结论的范围和下一步问题是什么。

常用段落骨架：

> 命题句。依据句。解释句。限制或推论句。

材料不能连续堆在一起。引用法条后说明它提供的是构成要件、法律效果还是评价标准；引用案例后说明关键事实、法院理由和该案能够支持的有限规则；介绍域外法后回到中国法的条文结构。

### 5. 能直说就不要反说

“并非 A，而是 B”只有在确实需要纠正一个已有的错误命题时使用一次。以下写法通常是啰嗦的，应直接陈述 B：

- “并不是简单地……而是……，换言之……也就是说……”
- “表面上……实际上……，从某种意义上说……”
- “不能仅仅……还要……，这意味着……”（同一段反复出现）

若 B 是本文真正的判断，直接写“问题在于 B”“应当区分 A 与 B”“该条只规定……，并未规定……”。不要先否定一句，再用两三句重复肯定同一内容。

## 二、句子层面的约束

### 推荐

- 用具体主语：`该条文`、`该裁判`、`这一解释`、`权利人`、`使用者`。
- 用动词说明法律动作：`限定`、`排除`、`涵盖`、`推导`、`配置`、`区分`、`归入`、`承担`。
- 先写条件，再写效果：`只有在……时，才构成……`；`即使……，也不当然产生……`。
- 长句只在各分句之间有明确的因果、条件或转折关系时使用；一个句子包含三个以上逗号时，检查能否拆开。

### 删除或谨慎使用

下列词语不是绝对禁用，但在本地原文中通常不承担必要的论证功能，生成时应优先删除或改为具体判断：

`根本性困境`、`底层逻辑`、`破局`、`抓手`、`赋能`、`闭环`、`全景式`、`立体化`、`多维度`、`图景`、`赛道`、`颗粒度`、`组合拳`、`一盘棋`、`双轮驱动`、`生态`、`引领`、`重塑格局`、`深刻变革`、`巨大冲击`、`极具说服力`、`完美契合`、`一针见血`、`泼冷水`、`神奇的工具`、`破题`、`赋予全新动能`。

对应改法不是换成另一个抽象名词，而是写出具体内容：

| 不要写 | 直接改写为 |
|---|---|
| 根本性困境 | 哪一条规则无法适用，或哪两种法律效果发生冲突 |
| 底层逻辑 | 规范目的、权利基础或利益关系 |
| 破局/破题 | 解释方案、判断标准或法律效果 |
| 抓手 | 依据、入口、标准或条文 |
| 赋能 | 使……能够、为……提供依据 |
| 立体化治理 | 区分主体、行为类型和责任后果 |
| 多维度分析 | 从……、……两个方面分别分析 |
| 图景/格局 | 现状、关系、分歧或规则结构 |
| 完美契合 | 与……相符；能够解释…… |
| 深刻揭示 | 说明、表明、指出 |

## 三、摘要、标题和结语

摘要直接写“问题—既有路径的限度—本文判断—规则后果”。不要写“本文首先……其次……最后……”，也不要把摘要写成目录。

标题使用“对象 + 争点/方法/规则”，例如“技术措施保护与合理使用的冲突及法律对策”“知识产权‘客体—对象’区分论解析”。少用“赋能”“路径创新”“范式升级”等无法独立检验的标题词。

结语只收束已经论证的内容，说明原则、例外、适用边界和仍待解决的问题。不要在结尾突然加入“新时代”“高质量发展”“中国方案”等未在正文论证的宏大判断。

## 四、生成前的四问

1. 这句话的主语和法律动作是否明确？
2. 下一句话是在提供依据、解释依据，还是说明限制？如果三者都不是，删除或移位。
3. 本段是否从命题推进到了规则后果，而不是同义改写？
4. 删除抽象修辞后，事实类型、法条关系和法律效果是否仍然清楚？
