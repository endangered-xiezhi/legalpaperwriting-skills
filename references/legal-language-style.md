# 核心期刊法学论文语言风格规则

本文件用于约束 agent 在使用本 skill 写作或修改时的具体语言风格，尤其是大小标题、论证开头、论据展开、段落结尾、内部层次和整体文风。目标是贴近用户提供的《法学研究》《法学家》样本文献。

## 一、大标题规则

大标题要同时呈现研究对象和论证角度，避免只写制度名称。

### 推荐结构

1. **对象 + 问题**
   - `不法原因给付的处理`
   - `人工智能侵权的过错责任`
   - `衍生数据的识别标准与产权配置`

2. **对象 + 方法/视角**
   - `不法原因给付与财产犯罪：以民刑法律效果的接续为视角`
   - `限定继承制转型研究：以遗产管理与限定继承的互动为视角`
   - `人工智能法学之类比方法及其省思：以AIGC著作权保护问题为例`

3. **概念重构式**
   - `个人信息作为对待给付`
   - `共同关系与共有类型`
   - `生命体尊严：生命尊严的法律内涵解释`

4. **规则建构式**
   - `非典型电子证券转让的一般规则`
   - `电子游戏著作权保护中思想与表达的界分方法`

### 避免

- `论公司法`
- `浅析人工智能侵权`
- `关于数据产权的研究`
- `完善个人信息保护制度的建议`

标题不要只标明领域，要标明问题、方法或规则产出。总标题应尽量控制在一个主要判断之内；如果副标题不能进一步限定对象、材料或分析视角，就删除副标题。总标题不必承诺全文涵盖所有保护部门法，应以全文真正完成的判断为准。

### 标题拟定与目录递进

标题的任务是提示论证，不是复述摘要。拟定标题前，先用一句话写出全文主张，再从主张中提取三个要素：研究对象、法律争点、法律效果。例如，若主张是“某类技术资产包含可保护表达和公共领域功能要素，整体不能确权，但特定不诚信复制行为可以受竞争法规制”，标题可以围绕“权利客体定性与竞争法保护”展开，不必把所有技术要素和法律部门都塞入标题。

全文目录通常按照以下关系推进：

1. **提出保护问题**：从交易、开源、裁判或技术事实说明现行规则为什么需要检视。
2. **清理既有规则**：按客体、构成要件或法律效果逐项检验著作权、合同、侵权责任、邻接权等既有路径。
3. **完成法律定性**：说明对象属于何种客体、利益或责任关系，并交代排除其他定性的理由。
4. **配置具体规则**：围绕行为类型、构成要件、证明责任、抗辩和救济范围展开。
5. **收束适用边界**：说明原则、例外和不能由本文结论推出的事项。

一级标题应承担上述推进中的一个环节，二级标题应说明该环节中的具体判断，三级标题只在确有不同标准、类型或理由时使用。相邻标题之间应有明确关系，例如“著作权边界”之后进入“既有私法保护限度”，再进入“权利客体定性”，最后进入“反不正当竞争法的补充保护”。若两个标题可以互换而不影响全文结构，说明标题没有承担论证任务。

标题可以采用下列形式，但须根据内容选择，不得机械套用：

- **对象＋属性判断**：`人工智能生成物的智力财产属性辨析`、`Agent Skills权利客体的法律定性`。
- **对象＋体系或范围**：`著作权法中传播权的体系`、`既有保护路径的适用限度`。
- **对象＋规则问题**：`技术措施保护与合理使用的冲突及法律对策`、`功能性要素的竞争法权益定位`。
- **对象＋关系或规制**：`知识产权法与反不正当竞争法一般条款的关系`、`反不正当竞争法的补充保护`。
- **判断＋限定对象**：`邻接权保护的客体障碍`、`分层保护不能完成整体定性`。

下列形式通常应当避免：

- 把所有标题强行改成主谓宾句式，导致“某某保护某某”“某某实现某某”反复出现。
- 连续使用“问题、困境、路径、机制、逻辑、体系”等抽象词，却没有写出所指的客体、要件或法律效果。
- 把标题写成“现状—问题—原因—对策”的固定模板，除非论文确实采用实证问题诊断结构。
- 使用“创新路径”“治理范式”“制度重塑”“多元协同”等不能从标题本身判断其内容的词。
- 在总标题中并列过多部门法，造成研究范围大于正文实际论证范围。

完成目录后，进行一次“目录复述测试”：只看标题，能否复述论文先提出何种事实或规范问题，随后排除哪些既有路径，最终确立何种法律属性，并通过何种规则处理？如果不能，应当先调整标题的论证任务，而不是继续润色正文。

## 二、一级标题规则

一级标题应当承担论证推进功能，通常对应“提出—分析—解决”的一环。

### 常见类型

- `一、问题的提出`
- `一、……的理论基础`
- `二、……的法理检视与澄清`
- `二、……二分法的不足`
- `三、……的三重识别标准`
- `四、……的中国方案`
- `四、……规则的原理和要件`
- `四、……的制度进路`
- `结语：面向……的……研究范式`

### 写法要求

- 一级标题不要只是“概念”“现状”“问题”“建议”。
- 一级标题可以包含一个动作，如检视、澄清、辨析、定性、配置或规制；但对象、属性和规则本身已经能够显示论证任务时，不必强行添加动词。
- 一级标题之间要能读出论证递进：先指出问题，再拆解框架，最后给出规则。

## 三、二级标题和内部层次

二级标题要更具体，通常完成分类、标准、功能或子论点展开。

### 推荐结构

1. **概念 + 论证动作**
   - `（一）基本界定：参与主体、技术基础及类型化线索`
   - `（一）用户任意停止信息给付权作为给定框架`

2. **类型 + 法律效果**
   - `（一）信息取代金钱型交易：对有偿性的再论证`
   - `（二）信息减免金钱型交易：给付结构的重新定位`

3. **标准 + 功能**
   - `1. 实质改变标准：数据结构、内容与形式的实质差异`
   - `2. 价值增值标准：使用价值与交换价值的显著提升`

4. **路径 + 评价**
   - `（一）扩张产品责任路径的体系困境`
   - `（二）主体资格路径的解释限度`

### 层级规则

- 一级标题回答“这一章推进什么”。
- 二级标题回答“这一部分证明什么”。
- 三级标题回答“这个标准/类型/理由是什么”。
- 不要出现只有编号没有实质标题的层级。
- 不要让二级标题只是材料名称，如“德国法”“美国法”；应写成“不得返还模式的制度困境”“允许返还模式的兴起及其回调机制”。

### 标题修改示例

修改标题时，优先把抽象评价改为具体的法律判断：

- `Agent Skills的保护需求与规范疑问`，可改为 `开源实践提出的保护问题`。
- `Agent Skills著作权保护的分层检视`，可改为 `Agent Skills的要素构成与著作权边界`。
- `既有私法保护路径的适用边界`，可改为 `既有保护路径的适用限度`，并在下级标题分别写明邻接权、合同、不当得利和商业秘密的具体障碍。
- `Agent Skills的权利客体定性`，可改为 `Agent Skills权利客体的法律定性`，使章节任务从目录中直接可见。
- `反不正当竞争法对Agent Skills的补充保护`，可改为 `反不正当竞争法的补充保护`，下级标题再写明一般条款范围、复制行为区分、商业道德、竞争损害和救济界限。

这些修改不是固定模板。每次应根据正文实际论证选择“对象＋属性”“对象＋边界”“对象＋适用限度”“对象＋法律定性”或“对象＋规制”等结构。

## 四、论证开头规则

段落开头不要直接堆材料，先交代本段在论证链中的位置。

### 1. 承接上文型

用于章节或段落开头。

模板：

> 上述分析表明，……并不能直接推出……。接下来需要进一步说明的是，……

> 如果说……解决的是……，那么……仍需回答……

### 2. 让步转折型

用于检讨既有观点。

模板：

> 这一观点能够解释……，但其问题在于……

> 上述路径并非全无根据，其合理性在于……。然而，当……时，该路径即难以维持。

### 3. 问题重置型

用于提出本文主张。

模板：

> 问题的关键不在于……，而在于……

> 与其将……理解为……，不如将其置于……框架下重新把握。

> ……并非……，而是……

### 4. 类型化开头

用于展开分类。

模板：

> ……并非同质现象，而是分布在从……到……的光谱之上。

> 以……为标准，可以将……区分为以下三种类型。

### 5. 法条联动开头

用于解释论。

模板：

> 单独适用……条虽然可以得出……，但这一结论未能充分回应……条所体现的规范目的。

> ……条提供的是法律效果，……条提供的是评价基础，二者需要在个案中作目的整合。

## 五、论据展开规则

每个核心段落宜采用“命题—依据—推论—限定”的内部结构。

### 基本格式

1. **命题**：本段要证明什么。
2. **依据**：法条、案例、学说、比较法、技术事实或政策后果。
3. **推论**：依据如何支持命题。
4. **限定**：该命题不适用于哪些情形。

### 常见论据类型

- **法条依据**：说明条文位置、构成要件、法律效果和体系关系。
- **案例依据**：提炼关键事实、争点、法院说理和有限裁判规则。
- **学说依据**：说明观点分歧，不把学者姓名当作论据本身。
- **比较法依据**：说明域外模式的制度背景、局限和对中国法的启发。
- **技术事实依据**：说明技术事实如何改变法律评价基础。
- **政策依据**：说明制度后果，并回到现行法结构。

### 禁止写法

- 只列法条，不解释法律效果。
- 只列案例，不归纳裁判规则。
- 只列学者，不说明分歧。
- 只说公平、效率、创新，不说明规则后果。
- 只介绍域外制度，不回到中国法。

## 六、段落结尾规则

段尾要收束本段贡献，并推动下一段，而不是自然停止。

### 推荐结尾类型

1. **推论型**

> 因此，……不宜被理解为……，而应定位为……

2. **限定型**

> 但这并不意味着……，其适用仍应限于……

3. **转接型**

> 在明确……之后，仍需进一步回答……如何配置法律效果。

4. **规则化型**

> 据此，可以形成如下判断规则：……

5. **回调型**

> 由此，……虽可作为原则，但必须通过……予以回调。

### 避免

- 段尾只停在“具有重要意义”。
- 段尾只说“因此应完善制度”。
- 段尾引入新概念但不解释。
- 段尾无法看出下一段为什么出现。

## 七、内部层次展开

### 一段内部

推荐顺序：

> 中心命题 -> 旧观点/旧规则 -> 问题或不足 -> 本文解释 -> 规则后果

### 一节内部

推荐顺序：

> 概念界定 -> 判断标准 -> 适用类型 -> 例外边界

### 一章内部

推荐顺序：

> 本章要解决的问题 -> 既有路径 -> 本文重构 -> 小结或转接

### 全文内部

推荐顺序：

> 旧框架失灵 -> 新坐标建立 -> 标准/类型展开 -> 中国法规则后果

## 八、整体文风

### 基本气质

- 判断克制。
- 句子密度高。
- 概念有层级。
- 结论有边界。
- 价值判断回到规范结构。
- 不直接喊口号。

### 句子和段落的直接表达

- 一句只承担一个主要判断；下一句负责依据、解释、限制或推论。
- 连接词必须表达真实的因果、转折、条件或收束关系，不用连接词制造段落的“学术感”。
- 段落按“命题—依据—推论—边界”推进。法条、案例和学说不能连续堆列；每项材料后都要说明它改变了哪一个判断。
- “并非……而是……”只用于纠正一个已有命题，且同一段通常只用一次。能直接说明的内容，不先反说再正说。
- 少用抽象的名词串联句子。把“困境、逻辑、机制、路径、格局”落实为具体条文、事实类型、构成要件、法律效果或证明责任。
- 删除“根本性困境”“底层逻辑”“破局”“抓手”“赋能”“闭环”“全景式”“立体化”“多维度”“图景”“组合拳”等不能独立说明法律问题的表达；详见 `local-corpus-style.md`。

### 推荐词汇

- 规范目的。
- 法律效果。
- 体系位置。
- 解释路径。
- 类型化。
- 差序规制。
- 弱保护。
- 回调机制。
- 构成要件。
- 请求权基础。
- 证明责任。
- 程序衔接。
- 规范评价。
- 中国方案。

### 慎用词汇

- 完善。
- 加强。
- 重视。
- 显然。
- 必然。
- 众所周知。
- 具有重要意义。

这些词不是绝对不能用，但用后必须接标准、要件、法律效果或制度边界。

## 九、智能体使用时的硬性要求

使用本 skill 生成或修改论文时，agent 必须遵守：

1. 大标题必须体现对象和论证角度。
2. 一级标题必须体现论证动作。
3. 每个章节开头必须说明本章要解决的问题。
4. 每个核心段落必须有中心命题。
5. 法条、案例、比较法和政策理由必须转化为推论。
6. 段落结尾必须收束或转接。
7. 不得输出只有“现状—问题—建议”的松散结构。
8. 不得输出只有价值口号而无规则后果的建议。
9. 结论必须说明边界、例外或回调机制。
10. 不确定的法条、案例、文献和页码必须标注待核验。
