# 法学术语中英对照与一致性提示

| 中文 | 英文 | 说明 |
|---|---|---|
| 请求权基础 | basis of claim / Anspruchsgrundlage | 德国法语境可保留 Anspruchsgrundlage |
| 民事法律行为 | juristic act / civil juristic act | 不宜简单译为 legal act 而不加说明 |
| 意思表示 | declaration of intent | 民法核心概念 |
| 法律效果 | legal effect | 与事实效果区分 |
| 构成要件 | constitutive elements / requirements | 结合具体语境 |
| 抗辩权 | right of defense | 注意与 defense 区分 |
| 形成权 | formative right | 如撤销权、解除权 |
| 撤销权 | right of revocation | 语境可指合同撤销或债权人撤销权 |
| 解除权 | right of termination / rescission | 合同解除语境常用 termination |
| 善意取得 | acquisition in good faith | 也可译 good-faith acquisition |
| 无权处分 | unauthorized disposition | 民法物权/合同语境 |
| 过错责任 | fault-based liability | 侵权责任 |
| 无过错责任 | no-fault liability / strict liability | 注意 strict liability 语境 |
| 过错推定 | presumption of fault | 侵权责任 |
| 因果关系 | causation / causal link | 侵权、刑法均需语境 |
| 相当因果关系 | adequate causation | 侵权法常见 |
| 注意义务 | duty of care | 侵权、公司法均可用 |
| 安全保障义务 | duty to ensure safety / security obligation | 需结合中国法说明 |
| 公司人格否认 | disregard of corporate personality / piercing the corporate veil | 公司法 |
| 揭开公司面纱 | piercing the corporate veil | 英美法语境 |
| 股东出资义务 | shareholder capital contribution obligation | 公司法 |
| 出资加速到期 | acceleration of capital contribution maturity | 中国公司法语境需解释 |
| 抽逃出资 | withdrawal of capital contribution | 公司法 |
| 董事信义义务 | fiduciary duties of directors | 公司法 |
| 忠实义务 | duty of loyalty | 公司法 |
| 勤勉义务 | duty of diligence / duty of care | 注意与侵权 duty of care 区分 |
| 商事外观主义 | commercial appearance doctrine | 商法语境 |
| 表见代理 | apparent agency | 民法 |
| 权利外观 | appearance of right | 民商法 |
| 比例原则 | principle of proportionality | 公法 |
| 信赖保护 | protection of legitimate expectations | 行政法、公法 |
| 正当程序 | due process | 公法、程序法 |
| 行政裁量 | administrative discretion | 行政法 |
| 罪刑法定 | principle of legality | 刑法 |
| 构成要件该当性 | fulfillment of constitutive elements | 刑法教义学 |
| 违法性 | unlawfulness | 刑法/民法语境不同 |
| 责任能力 | capacity for responsibility | 刑法 |
| 期待可能性 | possibility of expectation | 刑法 |
| 证明责任 | burden of proof | 诉讼法 |
| 证明标准 | standard of proof | 诉讼法 |
| 高度盖然性 | high probability | 民事证明标准语境 |
| 排除合理怀疑 | beyond a reasonable doubt | 刑事证明标准 |
| 既判力 | res judicata | 诉讼法 |
| 争点效 | issue preclusion | 需说明中国法语境 |
| 公序良俗 | public order and good morals | 民法 |
| 诚实信用原则 | principle of good faith | 民法 |
| 公平原则 | principle of fairness | 民法 |
