# 法条与案例拆解

## 法条拆解表

| 项目 | 要问的问题 |
|---|---|
| 条文位置 | 位于哪部法律、哪一编章、与哪些条文相邻？ |
| 规范对象 | 调整谁与谁之间的法律关系？ |
| 构成要件 | 适用需要哪些事实条件？ |
| 法律效果 | 满足要件后产生什么权利、义务、责任或抗辩？ |
| 体系关系 | 与一般条款、特别规则、司法解释如何衔接？ |
| 解释争议 | 文义、体系、目的解释会导向什么差异？ |
| 适用边界 | 哪些情形应排除或限缩？ |

## 案例拆解表

| 项目 | 内容 |
|---|---|
| 元信息 | 案号、法院、日期、案由、审级、来源 |
| 关键事实 | 与争点有关的事实，不复述无关案情 |
| 争点 | 当事人真正争的法律问题 |
| 规范依据 | 法院援引的法条、司法解释、规则 |
| 说理路径 | 法院如何从事实走向法律效果 |
| 裁判结论 | 支持、驳回、改判、发回等 |
| 可用方式 | 支持本文、反驳本文、区分事实、归纳类型 |

## 裁判规则归纳

不要写：

> 该案说明法院支持……。

应写：

> 在……事实类型下，法院将……评价为……，并以……作为主要理由。因此，该案可支持的有限规则是……。

## 案例比较

比较案例时优先比较：

- 事实差异。
- 争点差异。
- 援引规范差异。
- 说理强度差异。
- 裁判层级和效力差异。

## 使用限制

- 普通裁判文书不能当然代表通说。
- 指导性案例也要注意裁判要点的适用范围。
- 样本数量不足时，不作“司法实践普遍认为”的结论。
