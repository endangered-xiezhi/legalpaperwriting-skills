# 法学论文文本评估规则

自动评估只处理能用规则识别的问题，不能替代作者、导师或编辑的实质判断。

## 可信度

- 模糊引用：“有学者认为”“司法实践普遍认为”但没有来源。
- 未处理占位符：“待核验”“待补充页码”“待补充案号”。
- 未来年份或明显异常年份。
- 绝对化判断：“毫无疑问”“必然”“无可争辩”。

## 法学材料使用

- 法条后缺少解释：只贴条文，不说明构成要件、体系位置、规范目的。
- 案例后缺少分析：只给案号或结论，不归纳裁判规则。
- 比较法直接移植：“德国法如此，所以我国应当如此”。
- 政策判断替代规范论证：“更公平”“更有效率”但没有回到现行法。

## 术语一致性

检查同一法学概念是否混用：

- 请求权基础 / 请求权规范基础。
- 法律行为 / 民事法律行为。
- 形成权 / 撤销权 / 解除权。
- 善意取得 / 即时取得。
- 公司人格否认 / 法人人格否认 / 揭开公司面纱。
- 注意义务 / 安全保障义务。
- 过错推定 / 无过错责任。

## 格式

- 空脚注。
- 参考文献缺少类型标识。
- 中文语境使用英文标点。
- 标题编号体系混用。
- 法规、案例、文献引用格式混杂。

## 语体

- 口语化表达。
- 自称混用。
- 结论过满但缺少限制条件。
- 抽象 AI 式修辞（如“根本性困境”“底层逻辑”“抓手”“赋能”“立体化”“破局”）未落实为具体的条文关系、事实类型或法律效果。
- 同一句或同一段反复使用“并非……而是……”“换言之”“也就是说”，先反说再正说，未增加新的依据或限制。
- 一个长句承载多个判断、因果和转折，影响句子之间的逻辑层次。

## 论证逻辑

- 连续断言但缺少推理连接。
- 多个案例并列罗列但未类型化。
- 引文、法条或案例后直接进入新话题。
- 因果前提未论证。
- 总结句堆砌前文未展开概念。

## 核心期刊风格专项

- 摘要是否只是目录式介绍，而没有提出核心命题。
- 新概念是否只命名，未产生规则后果。
- 结论是否一刀切，缺少例外、强弱区分或回调机制。
- 比较法是否停留在介绍，未回到中国法解释论。
- “应完善”“应加强”后是否缺少具体标准、类型或要件。
- 标题是否只是“相关概念”“存在问题”“完善建议”，而没有体现论证动作。
- 段落开头是否直接堆材料，没有交代本段要证明什么。
- 段落结尾是否没有收束、限定或转接。

## 推荐流程

1. 生成或修改一节后运行 `python scripts/review.py paper.md`。
2. 先处理 error，再处理 warning。
3. 对脚本无法判断的问题，使用 `human-review-checklist.md` 人工复核。

其中 `S-03` 至 `S-07` 是本地原文语言规则：它们只作提示，不要求机械删除所有转折或抽象词；若该词是法律术语或文章确已给出具体定义，应由人工保留或改写提示。
